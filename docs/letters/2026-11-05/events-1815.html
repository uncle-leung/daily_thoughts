4. 平陆运河便携引航终端航海保障服务功能再丰富

中新网南宁11月5日电 (记者 杨陈)记者5日从中国交通运输部南海航海保障中心南宁通信中心(以下称南宁通信中心)获悉，该中心日前完成平陆运河电子江图、船舶定位等信息叠加至便携引航终端，实现平陆运河航道环境与船舶航行信息的一体化展示。据悉，围绕平陆运河引航业务需求，南宁通信中心承担了广西引航中心开展的便携引航终端(PPU)应用建设项目，并在此基础上，完成了基于S-100标准的智能引航服务开发，进一步丰富便携引航终端航海保障服务功能。S-100是国际海道测量组织(IHO)提出的新一代通用海上数据模型标准，可在标准电子海图上叠加水位、水深、航行规则等与航行安全相关的信息图层，实现联动运算和助航信息自动推送。按照国际海事组织(IMO)时间表，2029年1月1日起新装电子海图显示与信息系统(ECDIS)必须满足S-100标准。
